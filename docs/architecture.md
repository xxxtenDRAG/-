# 系统架构

## 一句话定位

面向中小型家禽（以鹅为核心示范场景）养殖场，用标准化异常行为事件驱动一套 LangGraph 多智能体 RAG 系统，把"看见的现象"自动转化为可溯源的风险等级 + 诱因分析 + 处置建议，并在前端完成监控、告警、问答的完整交互闭环。

## 三层解耦

```
+---------------------------------------------------------+
|  交互域  Interaction Domain      （前端，Vue3）          |
|  监控台 / 事件模拟控制台 / 告警中心 / 智能问答 / 知识库   |
+-----------------------+---------------------------------+
|  REST + SSE                                            |
+-----------------------+---------------------------------+
|  研判域  Reasoning Domain        （后端，FastAPI）        |
|  LangGraph 五智能体 · 双通道检索 · 溯源 · 告警落库        |
+-----------------------+---------------------------------+
|  * 唯一耦合点：BehaviorEvent 契约                       |
+-----------------------+---------------------------------+
|  感知域  Perception Domain       （可缺席 / 可替换）      |
|  L0 事件模拟器 | L1 预生成检测视频 | L2 检测+跟踪+规则   |
+---------------------------------------------------------+
```

**关键约束**：交互域和研判域永远不 import、不感知感知域的实现细节。感知域通过 HTTP POST 一份符合契约的 JSON 进来，仅此而已。

## 分层架构

| 层 | 组件 | 职责 |
|----|------|------|
| 前端展示层 | Vue3 + Element-Plus + ECharts + Pinia | 监控台、模拟控制台、告警中心、智能问答、知识库管理；SSE 打字机渲染 |
| API 网关层 | FastAPI (Python 3.11) + Pydantic | 事件接收、SSE 流式输出、告警查询、文档上传、鉴权与参数校验 |
| 多智能体业务层 | LangGraph | Query 理解 → 检索 → 评估 →（循环）→ 生成 → 溯源，状态图驱动 |
| 知识层 | ChromaDB + NetworkX + Vision Adapter | 向量检索、知识图谱多跳推理、Louvain 社区检测、视觉事件接入 |
| 数据持久层 | MySQL 8 + ChromaDB (persist) | 事件、告警、会话、消息、知识库元数据 |

## 两条数据链路

### 链路 A · 事件链（核心创新）

```
[视觉/模拟器] --POST BehaviorEvent--> /api/v1/vision/events
→ 阈值与去抖校验 → 落库 behavior_event
→ 触发 LangGraph 研判 → 生成风险报告
→ 落库 alarm_record + 通过 SSE 推送给前端
→ 前端告警弹窗 + 语音/提示音 + 报告明细
```

### 链路 B · 问答链

```
[用户在智能问答页输入] --POST /api/v1/chat/stream--> SSE
→ Query 理解 Agent（意图识别、改写、实体抽取）
→ 双通道检索（向量 + 图谱）→ 评估 Agent 判定是否重查（≤3 轮）
→ 生成 Agent 流式输出 → 溯源 Agent 附加引用
→ 前端打字机渲染 + 来源卡片
```

## 视觉能力四级路线（L0 → L3）

| 等级 | 名称 | 需要 CV 能力 | 工作量 | 演示效果 |
|------|------|-------------|--------|----------|
| L0 | 事件模拟发生器 | 无 | 1-2 天 | 中（数据真实流转） |
| L1 | 预生成检测视频 | 无（只跑推理命令） | 1 周 | 中高 |
| L2 | 检测+跟踪+规则引擎 | 低（会调库+调参即可） | 2-3 周 | 高 |
| L3 | 自训练行为模型 | 高 | 2-3 月 | 很高 |

**决策**：M0-M4 全部按 L0/L1 推进，先把赛事必需的材料做齐；M5（省赛后）有余力再上 L2。
