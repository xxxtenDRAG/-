## 里程碑总表

| 里程碑 | 时间 | 目标 | 交付物 | 验收标准 |
|--------|------|------|--------|----------|
| M0 立项与骨架 | 2026.10.08 - 11.07 | 仓库、契约、环境、需求收敛 | 仓库初始化；behavior-event.schema.json v1.0；openapi.yaml 草案；docs/architecture.md；知识库书单 | 前端能拿到 mock 事件并渲染告警卡片；后端能接收并落库一条事件 |
| M1 研判内核贯通 | 2026.11.08 - 12.19 | 从事件到报告的全链路 | LangGraph v0.1→v0.2；ChromaDB 知识库（≥3 本书）；报告生成 CLI 脚本 | 命令行喂入一条 limp 事件，输出含风险等级+诱因+建议+引用的报告 |
| M2 交互闭环 | 2026.12.20 - 2027.02.06 | 前后端联调，五大页面可用 | 监控台/模拟控制台/告警中心/智能问答；SSE 打字机；L1 预生成检测视频 | 点击"模拟跛行"→ 3 秒内前端弹出带等级色的告警报告，含可展开引用 |
| M3 参赛材料+校赛 | 2027.02.07 - 03.31 | 大创申报书+校赛 | 申报书、架构图、ER 图、演示视频 v1、答辩 PPT v1、软著材料 | 完整演示视频 ≤5 分钟；申报书通过校内初审 |
| M4 大创推荐+省赛 | 2027.04.01 - 05.20 | 省级赛提交、大创立项 | 省赛作品包、用户手册、测试报告、20 组评估问答集 | 省赛提交成功；大创获校级以上立项 |
| M5 视觉升级+打磨 | 2027.05.21 - 06.30 | L2 规则引擎（有余力） | YOLO 个体检测+ByteTrack+规则引擎 | 真实视频能自动产出 limp/gather 事件并触发全链路 |
| M6 国赛冲刺 | 2027.07.01 - 08.20 | 国赛材料+现场演示 | 答辩 PPT v2、现场演示脚本、备用录屏、FAQ 手册 | 现场 8 分钟内讲完并完成一次完整演示，零故障 |

## 需求优先级（砍需求顺序，从下往上砍）

| 优先级 | 需求 |
|--------|------|
| P0 必须 | 事件契约、模拟器、LangGraph 研判、SSE 报告、告警中心、智能问答、MySQL 落库 |
| P1 重要 | 知识图谱通道、L1 检测视频、看板统计、知识库管理页、报告反馈 |
| P2 加分 | L2 规则引擎、Redis 缓存、Docker 部署、多摄像头、用户体系 |
| P3 规划 | L3 自训练模型、Neo4j、RTSP 接入、移动端 |
